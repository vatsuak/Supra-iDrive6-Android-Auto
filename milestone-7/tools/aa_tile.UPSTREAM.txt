Local adaptations:
- Compile/link with QNX SDP 6.5 headers and runtime, rather than handwritten
  system prototypes, custom startup code, or link-only stub libraries.
- Use native sockaddr_in and signal constants.
- Strict arguments, live daemon PID and exact connected state, controller-source
  validation, and suppression of tile presses while hidden/stopping.
- Kernel-held RAM instance lock; default 120-second duration.
- Report send/cleanup errors; fatal signals write only to the RAM log.

Firmware-specific DSI object offsets and vtable slots remain experimental.
This does not establish Supra hardware compatibility, arbitrate a real CarLife
session, or add phone name/battery fields or Android Auto artwork/labels.
